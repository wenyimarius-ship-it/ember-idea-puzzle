# Idea Puzzle 首轮体验验收

本轮以任务中给出的《Puzzle 想法拼图 · 产品文档 v1》要求为实现依据；仓库内未发现另附的产品文档文件。

## 实现范围

入口为轻量的两念头试玩，不展示自由画布、分类、JSON 或教程。示例是固定的三张卡片，三种组合分别对应事先写定的关系和行动建议，不随机拼接解释。

自定义路径接受两至三个念头；用户选择并可修改关系后，才出现行动步骤。关系文案明确来自用户选择；自行改写关系时使用中性的行动建议，不根据任意文本推断因果。行动可选、可改、可自写；留空时采用当前关系的第一条建议。

结果卡明确显示本次体验已完成，包含两个念头、关系和小动作。复制成功有反馈，浏览器剪贴板权限失败时提供可选中的文本，不假报成功。「再来一组」返回入口，「继续整理」才加载原画布。

没有加入 AI、账号、积分或新的依赖。没有修改 Vercel 项目、域名或 DNS。

## 数据兼容

- 保持 `ember-idea-puzzle-v1` 和 `version: 1` 数据结构。旧卡片内容、坐标、分类、颜色、主题及行动照常恢复。
- 首轮示例、自定义输入及结果只在当前页面内存中；刷新结果页会回到入口，应先复制结果。
- 完成首轮不会写入旧存储，也不会把示例自动加入画布。进入画布同样只读取；实际编辑后才保存。
- `sessionStorage` 中独立的 `idea-puzzle-view` 仅记录本标签页是否已进入进阶区，让刷新画布仍停留在画布；不可用时仍能操作，只是不保留导航位置。
- 原画布拖动、编辑删除、分类颜色、主题、单行动、存储失败提示、键盘和导出保留。JSON 导入原先没有实现，本轮补齐：文件大小上限 2MB，校验版本、颜色、位置、重复 ID、主题/行动引用；确认替换后先持久化成功，再替换内存画布。无效文件、取消或保存失败均不替换当前画布。
- 不支持跨设备同步；清理网站数据仍会清除画布。使用导出文件备份。

## 自动验证

运行 `npm run build`、`npm test -- --workers=2`。

覆盖：三种示例组合、首张取消再选、空行动默认值、用户关系确认/四个模板、自定义关系改写及动作编辑、复制成功与权限失败兜底、再来一组、进入原画布、v1 数据逐字段不变、JSON 导入取消/成功/无效文件/导出回读、减少动态效果，以及原工具整套回归。

测试尺寸：375×812 手机触控模拟、1440×1000 桌面。桌面跳过触控滚动专项，手机执行该项；其余不跳过。本次最终结果：33 项通过、1 项按设计跳过；生产构建在两个尺寸下的自定义修改关系、结果、进阶区进入与返回检查均通过，无观察到的页面、控制台或 HTTP 资源错误。

自动化不能证明陌生访客 90 秒完成，也不能替代真实 iOS/Android 的触控和系统剪贴板验收。下一步只做个人试玩与三名陌生访客验收，目标至少两名独立完成，不继续扩展功能。
