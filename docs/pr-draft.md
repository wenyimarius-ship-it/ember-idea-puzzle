# Idea Puzzle：用两个念头完成首次拼合与小动作

## 改变

首次进入不再要求访客理解自由画布。选择两张固定示例卡片即可看到有依据的关系、选取或填写一个小动作，并生成可复制的结果卡；结果卡明确表示本次体验已经完成。「写我自己的」使用用户选择/修改的关系，不推断任意念头之间的因果。

原画布延后到可选的「继续整理」，复用原有编辑、拖动、颜色分类、主题、行动、键盘、本地存储与导出。补齐原先缺失的 JSON 导入，校验并确认后才替换；首次示例不改动 v1 用户数据。未增加依赖，未修改其他项目、DNS 或 Vercel 配置。

- 原工具回归、旧数据逐字段保持、导入取消/成功/无效文件/导出回读通过。
