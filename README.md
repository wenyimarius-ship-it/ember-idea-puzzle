# Idea Puzzle · 想法拼图

一个独立的互动思考桌面：记录零散想法、发现联系，并把其中一个变成下一步行动。纯前端，无账号、数据库或运行时第三方服务。

## 本地运行

需要 Node.js 20.19+ 或 22.12+（本次验证使用 Node.js 24.22.1）。

```sh
npm ci
npm run dev
```

在受限云环境中，如果默认 npm 缓存目录不可写，可使用 `npm ci --cache /workspace/.npm-cache`。开发服务器默认端口为 5173。

```sh
npm run build
npm run preview
```

构建产物位于 `dist/`，可用任意静态文件服务器托管。

## 使用方式

- 点击「新想法」创建卡片，点击卡片正文在编辑栏编辑多行文字。
- 按住卡片右上角手柄自由拖动。键盘聚焦手柄后，方向键移动 10px，Shift + 方向键移动 40px。
- 手机上滑动画布浏览，按住手柄才拖动卡片；编辑区位于画布下方。
- 设置颜色与自由文本分类；选取已有主题或输入新主题名称创建并加入。主题边框随成员位置变化，支持重命名和移出。最后一张成员移出后，空主题自动移除。
- 选中卡片设为下一步，输入具体行动并勾选完成。一次聚焦一个行动，替换已有行动会要求确认。
- 画布选项提供 JSON 导出、清空与恢复示例；删除、清空和恢复均有确认。
- 右上角「?」可重看首次使用指南。

## 数据与限制

状态使用 `localStorage` 自动保存，键为 `ember-idea-puzzle-v1`，包含卡片文字、颜色、分类、位置、主题和行动状态。刷新后自动恢复。内容不会发送到服务器。

保存被禁用或配额不足时显示警告，当前页面仍可编辑和导出。损坏或不兼容的已存数据不会自动覆盖，应用使用临时示例并提示；可先在浏览器开发者工具中备份原始键值，再移除该键并刷新。JSON 导出用于备份，本 MVP **不提供导入**。

不同浏览器、设备、浏览器配置与网站来源之间不会同步。清理网站数据或隐私模式可能导致数据丢失；定期导出备份。多个标签页同时修改时，以最后保存的状态为准。画布为 2460 × 1800px 的有限空间；分组表示主题关系，卡片仍可独立移动，没有缩放或整组拖动。

## 测试

```sh
# 标准环境首次准备浏览器
npx playwright install chromium
npm test
```

测试配置优先使用 `CHROMIUM_PATH`，否则使用本机 `/usr/bin/chromium`（如果存在）；没有系统 Chromium 时使用 Playwright 安装的版本。

测试覆盖桌面与手机尺寸下的创建、多行编辑、颜色与分类、主题创建/合并/重命名/移出、行动替换与完成、刷新恢复、鼠标及模拟触控拖动、键盘移动、防误删、清空取消/空状态/恢复、导出文件内容、存储写入失败与损坏数据保护。手机专项还验证触控滚动画布。测试会自动启动开发服务器。

手机测试使用 Chromium 触控模拟，不能替代真实 iOS Safari 和 Android 设备验收。当前仓库原无测试；本次新增 Playwright 端到端测试。

## 代码结构

- `index.html`：入口、页面元信息
- `src/main.js`：视图、事件、指针拖动、编辑与保存
- `src/state.js`：示例、存储键、数据结构验证
- `src/style.css`：响应式桌面、卡片与交互样式
- `tests/puzzle.spec.js`：浏览器功能回归
- `playwright.config.js`：桌面/手机项目和本地测试服务

## 独立 Vercel 部署

1. 将这些变更提交并推送到 **此仓库**。
2. 在 Vercel 新建独立项目，导入 `wenyimarius-ship-it/ember-idea-puzzle`。仓库根目录即项目目录（Vercel 中 Root Directory 保持 `.`）。
3. Framework Preset 选 Vite，Node.js 选 24.x，Install Command 为 `npm ci`，Build Command 为 `npm run build`，Output Directory 为 `dist`。无需环境变量。
4. 部署后先打开 Vercel 实际提供的 `.vercel.app` 地址，确认 HTTPS、静态资源加载、无控制台错误，并重复创建/拖动/主题/行动/刷新/导出的验收流程，在真实手机上补验。
5. 只有默认地址已验证可用后，才另行将真实链接加入 Lab 项目列表。

本次未执行部署，没有生成或验证线上 URL。不要预设项目域名，不绑定 `ideas.mariustang.com`，不修改 Porkbun DNS 或现有 Lab 配置。本地与部署后的域名是不同存储来源，本地想法不会自动出现在部署站点。
